# Charity Events - Client Website

This is the client-side website for the Charity Events platform. Users can browse events, view event details, and register for events.

## Features

- **Home Page**: Displays all upcoming charity events
- **Event Details**: Shows detailed information about each event including recent registrations
- **Event Registration**: Allows users to register for events with ticket purchase
- **Search**: Search and filter events by various criteria

## Files Structure

- `index.html` - Main homepage
- `event.html` - Event details page
- `registration.html` - Event registration form
- `search.html` - Event search page
- `css/style.css` - Styling for all pages
- `js/` - JavaScript files for each page functionality
- `images/` - Event images

## Quick Start (Windows)

1. **Make sure the API server is running first** (run `start.bat` in `usernameA3-api` folder)
2. **Double-click `start.bat`** - This will automatically open the website in your browser

## Manual Usage

1. Open `index.html` in a web browser
2. Browse available events
3. Click on an event to view details
4. Use the "Register for this event" button to register
5. Fill out the registration form with your details

## API Dependencies

This client website requires the API server to be running on the same domain or with proper CORS configuration.

## Browser Compatibility

- Modern browsers with ES6+ support
- Fetch API support required
